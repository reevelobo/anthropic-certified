## Quick Start

!!! tip "Recommended Study Order"
    1. **[M01 · MSO Foundations](certification/claude_certified_developer-foundation/modules/m01_MSO_foundation/index.md)** — vocabulary and mental models used everywhere else
    2. **[M02 · Production Prompting, Agents & Tools](certification/claude_certified_developer-foundation/modules/m02_production-grade_prompting_agents_tools/index.md)** — the largest section; all production patterns
    3. **[M03 · Claude Code, MCP & Integration](certification/claude_certified_developer-foundation/modules/m03_claude_code_mcp_integration/index.md)** — hands-on Claude Code and MCP server patterns
    4. Browse **[Courses](modules/index.md)** to fill any knowledge gaps before the exam
