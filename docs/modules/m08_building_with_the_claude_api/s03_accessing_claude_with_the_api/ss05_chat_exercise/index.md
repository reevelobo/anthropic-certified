# Exercise: Build a Chatbot Using the Three Helper Functions

Make a chatbot using the three helper functions we just put together.

1. Prompt the user to enter some input using the built-in `input()` function.
2. Add the user's input to a list of messages.
3. Call the API.
4. Add the generated text to the list of messages.
5. Print the generated text.
6. Repeat from step 1.

## Flow

```text
User Input
    ↓
Add User Message
    ↓
Call API
    ↓
Add Assistant Response
    ↓
Print Response
    ↓
Repeat
```
