### Project Execution with Description–Discernment Loops

**Estimated Time:** 30–60 Minutes

---

### Learning Objectives

By the end of this lesson, you will be able to:

- Apply **Description** and **Discernment** skills to a real-world project.
- Engage in productive **Description–Discernment feedback loops**.
- Create results through human-AI collaboration that exceed what either humans or AI could achieve independently.

---

### Exercise: Project Execution with Description–Discernment Loops

This exercise focuses on applying everything learned so far by executing the project you planned earlier using both Description and Discernment competencies.

---

### Step 1: Review Your Project Plan

Before beginning execution:

- Retrieve the project plan created in Lesson 5.
- Review your delegation decisions:
  - Which tasks require human expertise?
  - Which tasks can leverage AI capabilities?
  - Which tasks benefit from collaboration?
- Refine the project plan if your understanding has evolved since it was originally created.

---

### Step 2: Prepare Your Description Strategy

Start a conversation with Claude and introduce your project.

Before execution, establish expectations using the three Description components.

---

#### Product Description

Define:

- The outputs you need from Claude.
- Desired formats.
- Writing style and tone.
- Length requirements.
- Expected level of detail.

Questions to consider:

- What should Claude create?
- What should the final result look like?
- Who is the intended audience?

---

#### Process Description

Define:

- How Claude should approach the work.
- Specific methodologies to use.
- Frameworks to follow.
- Preferred workflows or reasoning approaches.

Questions to consider:

- Should Claude follow a particular process?
- Are there required steps?
- Are there preferred methods for analysis or creation?

---

#### Performance Description

Define how Claude should interact with you.

Examples:

- Concise or detailed responses
- Supportive or critical feedback
- Creative or analytical focus
- Collaborative brainstorming or direct execution

Questions to consider:

- What type of thinking partner do you need?
- Should Claude challenge assumptions?
- Should Claude prioritize efficiency or exploration?

---

### Discuss Expectations

Work with Claude to establish:

- Shared goals
- Working style
- Communication preferences
- Success criteria

This creates a strong foundation for collaboration.

---

### Step 3: Execute the Project Using Description–Discernment Loops

For each project task, follow a continuous loop of:

**Describe → Discern → Refine → Integrate**

---

### 1. Describe

Use Description skills to clearly communicate what you need.

---

#### Product Description

Be specific about:

- Deliverables
- Desired outcomes
- Format
- Quality expectations

---

#### Process Description

Guide Claude's approach by specifying:

- Methods
- Steps
- Frameworks
- Reasoning process

---

#### Performance Description

Define how Claude should engage with you.

Examples:

- Provide detailed explanations
- Challenge weak assumptions
- Offer concise recommendations
- Collaborate as a brainstorming partner

---

### 2. Discern

Evaluate the quality of both the output and the interaction.

---

#### Product Discernment

Evaluate:

- Accuracy
- Completeness
- Relevance
- Quality
- Usefulness

Questions:

- Does this meet my requirements?
- Is it correct?
- Does it solve the problem?

---

#### Process Discernment

Evaluate:

- The reasoning process
- Task execution quality
- Adherence to instructions

Questions:

- Did Claude follow the intended process?
- Were important factors considered?
- Was the approach effective?

---

#### Performance Discernment

Evaluate:

- Communication quality
- Collaboration experience
- Adaptability

Questions:

- Is Claude interacting in a useful way?
- Is the level of detail appropriate?
- Is the interaction efficient?

---

### 3. Refine

Use discernment insights to improve future outputs.

---

#### Provide Feedback

Clearly explain:

- What worked well
- What did not work
- What should change

---

#### Clarify Requirements

Update your Description if necessary.

Examples:

- Add missing context
- Refine objectives
- Specify stronger constraints

---

#### Request Iterations

Continue working with Claude until the output meets expectations.

Refinement is an expected and valuable part of the process.

---

### 4. Integrate Human Expertise

AI should support, not replace, human judgment.

Apply your own:

- Experience
- Creativity
- Professional knowledge
- Critical thinking

Remember to:

- Add your unique perspective.
- Make final decisions.
- Select what to keep or reject.
- Accept responsibility for the final outcome.

---

### Continue the Loop

Repeat the following cycle throughout your project:

```text
Describe
    ↓
Discern
    ↓
Refine
    ↓
Integrate
    ↓
Repeat
```

Continue until your project is complete.

---

### Reflection

After completing your project, consider the following questions.

---

#### Description Patterns

- Which descriptions produced the best results?
- What types of instructions were most effective?
- What level of detail worked best?

---

#### Effort Distribution

- Which required more effort:
  - Description?
  - Discernment?
- Why do you think that was the case?

---

#### Plan vs. Reality

- How closely did execution match your original project plan?
- What adjustments were necessary?
- Which delegation decisions proved most effective?

---

### Key Learning Outcome

Successful human-AI collaboration is not a one-time interaction.

High-quality results emerge through repeated cycles of:

- Clear communication
- Critical evaluation
- Feedback
- Iteration

The Description–Discernment loop enables continuous improvement throughout a project.
